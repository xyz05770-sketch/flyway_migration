# flyway_migration
Demonstration of basic flyway CI/CD functionality

### Flyway Core

- Task 1: Create 2 sample table in Schema1 and 2 table in Schema2

- Task 2: Add one column in two of these tables.

- Task 3: Create a repeatable(R) migration which contains a stored procedure and migrate it.

- Task 4: Make some logic changes in that stored procedure and re-migrate it to all 3 environments namely DEV, TEST and PROD.
